# Flutter Theme Maker

Egy interaktív Flutter alkalmazás, amely lehetővé teszi egyedi Material Design témák létrehozását és előnézetét.

## Funkciók

- 🎨 Színválasztó elsődleges és másodlagos színekhez
- 🌓 Világos és sötét téma támogatás
- 👀 Valós idejű előnézet
- 📋 Generált téma kód másolása
- 🎯 Material Design komponensek előnézete

## Használat

1. Válaszd ki az elsődleges és másodlagos színeket a színválasztó segítségével
2. Váltogass világos és sötét téma között
3. Nézd meg a témát különböző komponenseken
4. Másold ki a generált kódot

## Telepítés

```bash
flutter pub get
flutter run
```

## Követelmények

- Flutter SDK 3.0.0 vagy újabb
- Dart SDK 3.0.0 vagy újabb
